# Segurança

## Como relatar uma vulnerabilidade

Não abra uma issue pública. Use o relato privado do GitHub: aba **Security › Report a vulnerability** neste repositório.

Inclua o que for possível: o que acontece, como reproduzir e qual o impacto. Nunca envie dados pessoais reais, extratos ou credenciais no relato.

## Versões cobertas

Só a versão mais recente da branch `main`.

## Escopo

O Solis é um projeto pessoal que roda no computador de quem o instala. O modelo de ameaças e as proteções estão em [`docs/Seguranca.md`](docs/Seguranca.md).
